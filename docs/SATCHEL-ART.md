# Satchel artwork and native bag chrome

The satchel button, portrait and pack slots use `AzerothCardBinder/Art/CardStack.tga`: a custom painted stack of gold-rimmed blue collectible cards with a luminous central diamond. It is a 128 × 128 uncompressed 32-bit TGA, referenced through `ACB.satchelIcon`. It ships inside the addon; no network fetch is needed in game. Original generated PNG and 256-pixel preview are kept in local `outputs/satchel-preview` and are not runtime dependencies.

Created with the built-in image-generation tool. The original was retained unchanged; the shipping file was resized and converted for the client's texture format.

Final generation prompt:

> Use case: stylized-concept. Production asset: a single World of Warcraft-style hand-painted fantasy inventory icon, square composition, readable at 32x32 pixels. Subject: three thick collectible fantasy trading CARDS fanned slightly, the front card almost upright, clearly rectangular portrait cards with clipped/chamfered corners, ornate aged brass/gold rims, dark navy-blue enamel card back with one large luminous pale-blue diamond/sigil at centre. The two rear cards show their edges behind the front card. Rich painterly brushwork and exaggerated chunky beveled highlights like a classic WoW inventory item icon. Warm golden edge lighting, deep blue-black recesses, worn tactile surfaces. Fill 85 percent of the square with the cards, close crop but keep all corners inside image. Background dark near-black vignette, no transparency. Beautifully painted, slightly illustrated, no realistic photography, no 3D render polish. No text, letters, numbers, logos, bag, pouch, envelope, ribbon, hands, characters, card faces or UI frame. Do not draw a playing-card suit. One finished square icon, no layout sheet, no labels.

`SatchelSkin.lua` applies the client's `HeldBagLayout` via `NineSliceUtil` to visual-only chrome, with a native tooltip-border fallback if unavailable. The satchel uses game rock background, native empty slots and item-quality frames, a native close button, and rounded grey action buttons. It does not inherit ContainerFrame inventory scripts or change the actual bag frames. Native layout and API references: [bag template](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_UIPanels_Game/Mainline/ContainerFrame.xml), [HeldBagLayout](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_SharedXML/Mainline/NineSliceLayouts.lua), [NineSlice utility](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_SharedXML/NineSlice.lua).

Check in game: the header's card portrait and metal surround, the native close button, selected/quality borders, empty slots, both pagination buttons and the keyring launcher. Try a layout/client without HeldBagLayout to verify the fallback. The art is deliberately simple enough for the 34-pixel launcher and 36-pixel pack slots; ownership and pack-size badges remain separate text.

## Face-down card back

`AzerothCardBinder/Art/CardBack.tga` is the matching full card-back artwork, created with the built-in image-generation tool using the card-stack image as a style reference. Every face-down pack card uses the same image, with no overlaid wordmark or rarity information. Flipping continues to warm the actual card model/background behind the back as before. The art is 256 × 358 pixels in a 256 × 512 uncompressed 32-bit TGA; the texture's UV crop is `(0, 1, 0, 358/512)`, preserving card proportions while using a client-compatible power-of-two texture. The untouched original PNG and the cropped preview are retained locally under `outputs/satchel-preview`.

Final generation prompt:

> Create a brand new production game texture, using the reference image only as the design/style reference. The reference contains fanned gold and blue cards. We need ONLY THE BACK OF ONE SINGLE CARD, completely flat, perfectly straight front-on orthographic view, no perspective, no tilt, no stack. Portrait aspect ratio 5:7, fill the entire image edge to edge with the rectangular card back. Match the reference's hand-painted World of Warcraft inventory-icon style and exact design language: thick worn antique golden brass chamfered outer frame, beautifully painted golden scrollwork running symmetrically up both sides, deep midnight cobalt-blue textured enamel panels, one large glowing pale icy-blue four-point diamond crystal at the exact centre, surrounded by a pointed gold diamond setting. Create a polished symmetric back for a collectible fantasy card. Rich painterly strokes, warm gold edge highlights and deep blue shadows, subtle engraved ornament in the corners. The whole card perimeter must be visible and must end at the image edges; no external scene or extra background. This is an actual texture used on face-down cards before flipping during a booster pack opening. At miniature size the large central diamond and gold frame must read immediately. Avoid tiny distracting microdetails. Absolutely no text, lettering, numbers, runes that look like letters, logos, characters, hands, card faces, bags, multiple cards, drop shadows cast onto an external background, UI controls, presentation sheet or mockup. ONE beautifully finished, flat card-back image.
