# Credits

## Creature catalog

`AzerothCardBinder/CatalogForever.lua` is generated by `tools/build-catalog.js` from the zone, dungeon and raid pages of
[wowforever.ninja](https://wowforever.ninja), an unofficial fan database for World of Warcraft: Forever. Only creature ids,
names, levels and ranks are used. As that site's "Where the data comes from" page explains, its baseline comes from
cMaNGOS classic-db (GPL-3.0) and Forever's own client files. This project is not affiliated with or endorsed by Blizzard
Entertainment.

To refresh the catalog, save the site's zone pages and the zones index page to a folder and run:

```
node tools/build-catalog.js <folder with the saved zone pages> <saved zones index page>
```

New Forever places that the site has no creature data for yet (the new zones, dungeons, Hyjal Summit and Barrow Deeps at the
time of writing) get cards once the site lists their creatures. Towns are left out because they hold friendly townsfolk.

## Gathering nodes

`AzerothCardBinder/CatalogNodes.lua` is generated by `tools/build-nodes.js`. Node names and skill levels come from the
"Gathering nodes" tables on the same wowforever.ninja zone pages. The object ids the game uses for each node come from the
`gameobject_template` table of the open-source [AzerothCore](https://github.com/azerothcore/azerothcore-wotlk) project (only
the id and name are used, to recognise a node in a loot window). Node meshes are named in the game's `tradeskillnodes`
folder, as listed by the WeakAuras model path list.

```
node tools/build-nodes.js <folder with the saved zone pages> <gameobject_template.sql> <ModelPathsClassicEra.lua>
```
