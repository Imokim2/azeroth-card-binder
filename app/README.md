# Companion app (planned)

The Windows desktop app that watches the add-on's saved-data file, uploads new ledger events and writes the data file the add-on reads back. It is built in Phase B of [docs/ROADMAP.md](../docs/ROADMAP.md). The contracts it must follow are in [docs/LEDGER-SPEC.md](../docs/LEDGER-SPEC.md) and [packages/shared/](../packages/shared/).
